Optional module · requires DMS

Quality events connected to controlled documents.

QualiGxP QMS handles planned change and unplanned quality events in the same workspace as document control. Every consequential transition requires an attributable reason and is written to immutable history.

Live QMS workspaces

The quality processes teams use every week.

Change control

Draft → Submitted → Under review → Approved → Implementing → Effectiveness review → Closed. Link affected controlled documents and create traced DMS revisions for approved “revise” impacts.

Deviations

Record contemporaneous facts for unplanned departures. Move from open through investigation, CAPA requirement or effectiveness review, and closure without mixing conclusions into the event record.

Investigations

Perform structured root-cause work linked to the parent deviation. The deviation cannot complete investigation while required linked investigations remain open.

CAPA

Plan, implement, and verify effectiveness. If the check fails, mark the CAPA ineffective, revise the action plan, and implement again before closure.

Computer system validation

CSV projects with a signed QA release gate.

Use CSV Validation Projects to show that a computerized system is fit for intended GxP use and remains in a controlled state. The supported path is GxP assessment, planning, specification, testing, deviation resolution, validation review, QA release, and periodic review.
