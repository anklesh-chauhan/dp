# Schedule M Gap Assessment

Use **Schedule M Gap Assessments**, **Site Master Files**, and the **Inspector Evidence Pack** export under **QMS** to structure Part I PQS readiness work for revised Schedule M / CDSCO expectations.

The customer remains responsible for validated intended use and for physical GMP Premises / Plant compliance. Gap assessment software does not certify facility Premises or Plant readiness.

## Where to work

| Screen | Use for |
| --- | --- |
| **Schedule M Gap Assessments** | Run a Part I clause checklist, update gap items with evidence notes, and sign lifecycle decisions. |
| **Site Master Files** | Maintain structured SMF sections and publish or retire with attributable signatures. |
| **Download Inspector Pack** | Export a JSON evidence pack (SOP sample, open quality-event counts, gap summary, CSV counts, training sample) when permitted. |

## Typical path

1. Create a gap assessment for a site and period; seed the Part I clause checklist.
2. Update each gap item status with notes and linked evidence as work progresses.
3. Advance the assessment through conduct, approval, and closure with attributable reasons.
4. Keep the Site Master File current and publish signed versions for inspection readiness.
5. Export the inspector pack only with `Export:InspectorEvidencePack` or gap-assessment view permission.
