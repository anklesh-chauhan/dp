# Laboratory OOS / OOT

Use **Laboratory OOS Events** under **QMS** for out-of-specification and out-of-trend laboratory results with Phase I / Phase II outcomes, investigation and Deviation gates, and signed closure.

The customer remains responsible for validated intended use and for physical GMP Premises / Plant compliance.

## Where to work

| Screen | Use for |
| --- | --- |
| **Laboratory OOS Events** | Record laboratory results, phase outcomes, evidence, and lifecycle decisions. |
| **Investigations** / **Deviations** | Complete linked investigation work; hand off confirmed OOS to Deviation when required. |
| **Quality Metrics** | View OOS lifecycle counts and overdue open started events (permission gated). |

## Typical path

1. Create an OOS/OOT event with laboratory context, result details, and ownership.
2. Complete Phase I assessment and record the phase outcome through the transition service.
3. Progress Phase II / confirmation work with investigation gates as configured.
4. Attach private evidence; preserve SHA-256 integrity states.
5. Close confirmed events only when investigation and Deviation gates are satisfied.

## Related QMS topics

- **Deviations** and **Investigations** — parent quality-event work for confirmed laboratory failures.
- **CAPA** — corrective action when the root cause requires it.
- **Schedule M Gap Assessment** — quality-control laboratory as a Part I topic.
